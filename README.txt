SMARTRAIL - KÖR APPEN STEG FÖR STEG

1. Ladda ner och installera Python:
   https://www.python.org/downloads/
   Viktigt: kryssa i "Add Python to PATH" vid installation.

2. Ladda ner och installera Visual Studio Code:
   https://code.visualstudio.com/download

3. Lägg dessa två filer i samma mapp:
   - app.py
   - smart_rail_data.xlsx

4. Öppna mappen i Visual Studio Code.

5. Öppna terminalen i VS Code:
   Terminal > New Terminal

6. Installera biblioteken:
   pip install streamlit pandas openpyxl

7. Starta appen:
   streamlit run app.py

8. Appen öppnas i webbläsaren.
